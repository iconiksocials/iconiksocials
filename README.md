- **Reporting.** Event dashboards fed from spreadsheet and CRM data.
- **AI workflows.** Reusable Claude skills that turn repeat marketing work into a one-step process.
- **Content engines.** AI video pipelines for YouTube, from script to voice to final cut.
- **Digital products.** Planners and templates published on Amazon KDP and Etsy.

## Selected work

**Event Playbook**
A planning tool for an events team. Event strategy, RACI ownership, interactive Gantt timelines and a "Plan My Event" wizard with forms per event type. One HTML file, saves progress in the browser, prints clean.

**Events Report**
A single view of a full fiscal-year event calendar across two brands, color-coded to flag shared events. Refreshed weekly from spreadsheet sources.

**Webinar Program**
A half-year webinar plan: seven sessions, partner co-hosted formats, a tradeshow pre-show session and a reseller enablement track.

**AI video channels**
Two YouTube channels built end to end with AI: bedtime stories for kids, and an inventor mascot for visual ASMR Shorts. Brand, scripts, voice and video.

**Publishing brands**
Planners, journals and templates, live on Amazon KDP.
